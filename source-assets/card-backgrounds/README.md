# Card backgrounds

The painted backgrounds behind the character in each card's picture window, one per grade (Higgsfield, GPT Image 2.5): r1 D moonlit stone courtyard, r2 C jade forest glade, r3 B sapphire sky and magic circle, r4 A amethyst rune circle, r5 S golden temple sunburst, r6 SSS prismatic ruby-gold burst. The game uses 400 px WebP copies, dist/assets/cardbg-r<grade>.webp.

## Each character's own scene

characters/<card id>.png: a scene painted for each card (43), from the card's story: Pupa's cherry blossom garden at night, Chantra's moonlit lotus lake, Phloeng's sky of flames, Asani's thunder peak, Qilin's golden palace among lucky clouds, and so on. The game uses 320 px WebP copies, dist/assets/cardbg-<card id>.webp (BACKDROPS in dist/cards.js); a card without one shows its grade's scene.
