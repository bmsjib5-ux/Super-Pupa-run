# Monster pictures

The base monsters of card mode, transparent PNG, painted with Higgsfield (GPT Image 2.5) from the earlier code-drawn designs (same shapes and colours). Each chapter recolours these with a CSS filter (look/hue in dist/cards-engine.js), so one picture serves a monster in every chapter. The game uses trimmed WebP copies, dist/assets/foe-<id>.webp. The thorn mushroom (walker) and its king were already painted (assets/thorn-shroom.webp).

Painted as their own monsters (no recolour): angelguard, cherub, angelknight, angelharp, angelshield, seraph, angelmage, stormangel, and the bosses archking and archqueen.

## Tower floors 101-150

Painted for the upper tower (no recolour), five zones of ten floors, each with six guards, a lord (odd floors), a queen (even floors) and a great boss (tenth floor):

- 101-110, arcane library: runeknight, spellbook, candlewisp, towergolem, shadowcat, mirrorwraith; towerlord, towerwitch; runedragon
- 111-120, haunted halls: tombguard, skullarcher, wraithhound, banshee, hauntdoll, ghostlantern; lichking, phantomqueen; phantomknight
- 121-130, beast garden: manticore, gargoyle, griffin, basilisk, nightunicorn, shelltortoise; wyvernlord, medusa; chimera
- 131-140, clockwork works: windupsoldier, cuckoobird, gearspider, steamowl, repairbot, sentinelorb; automatonking, hourglassqueen; clocktitan
- 141-150, starry throne room: starknight, cometimp, voidassassin, astromage, moonpriestess, crystalwarden; astralregent, voidempress; towersovereign
