# Gear icons

The eight pieces of gear every card wears, and the enhancement ore (Higgsfield, GPT Image 2.5, transparent): weapon, helm, armor, boots, ring, amulet, gloves, cloak, ore. The game uses trimmed 160 px WebP copies, dist/assets/gear-<name>.webp; the tier (ธรรมดา to ตำนาน) is shown by the colour of the icon's frame (cards.css .gear-icon.t1 to .t5).
