# Monster pictures

The base monsters of card mode, transparent PNG, painted with Higgsfield (GPT Image 2.5) from the earlier code-drawn designs (same shapes and colours). Each chapter recolours these with a CSS filter (look/hue in dist/cards-engine.js), so one picture serves a monster in every chapter. The game uses trimmed WebP copies, dist/assets/foe-<id>.webp. The thorn mushroom (walker) and its king were already painted (assets/thorn-shroom.webp).
